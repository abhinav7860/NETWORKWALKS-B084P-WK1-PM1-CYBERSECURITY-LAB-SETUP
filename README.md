## 🎯 Project Overview

This project focuses on building a virtual cybersecurity testing laboratory using Oracle VirtualBox and Kali Linux.

The objective is to configure a virtual machine, establish a dedicated network environment, and prepare a controlled laboratory for cybersecurity learning and practical exercises.

This setup provides the foundation for future cybersecurity activities involving networking, security testing, and hands-on laboratory exercises.

---

## 🎯 Objectives

- Install and configure Oracle VirtualBox.
- Create a dedicated VirtualBox NAT Network.
- Download and configure Kali Linux.
- Configure the Kali Linux network interface.
- Establish network connectivity.
- Verify IP configuration and internet access.
- Create a snapshot of the configured virtual machine.
- Document the setup process and practical experience.

## 🌐 Lab Network Configuration

| Configuration | Value |
|---|---|
| Network Type | NAT Network |
| Network Name | NatNetwork |
| IPv4 Network | 10.0.0.0/24 |
| Kali Linux IP | 10.0.0.2/24 |
| DHCP | Enabled in VirtualBox |

The network configuration is intended to provide Kali Linux with internet connectivity while maintaining a dedicated virtual network environment.

---

## 🖥️ Lab Environment

The laboratory consists of a Windows host machine running Oracle VirtualBox and a Kali Linux virtual machine.

The Kali Linux VM is configured to operate within the dedicated VirtualBox NAT Network.
